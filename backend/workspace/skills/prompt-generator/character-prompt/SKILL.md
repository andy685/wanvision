# 角色最终提示词（左侧半身肖像 + 右侧三视图）

生成的是一张角色设定参考图（character reference sheet），构图固定为：

- **左侧：风格化 3D 动画半身肖像**——头部到胸口完整入镜，正面或轻微 3/4 角度，五官、发型、服装领口清晰可见，作为脸部辨识度的锚点；不要大幅脸部特写
- **右侧：并列展示正面、90 度侧面、背面三张等高全身视图**——同一角色的三个全身视图等高并排，头顶与脚底对齐

**核心原则：一致性 > 美观 > 真人感。** 这张图是后续所有角色图片、视频参考的形象锚点，必须中性、清晰、可复用；角色必须明确是虚构的 3D 动画形象，不要生成真人照片、证件照、棚拍写真或真实演员感。

## 输出结构（按此顺序组装单段连贯中文）

```
风格化 3D 动画角色设定参考图，左侧为头部到胸口完整入镜的半身肖像，不是大幅正脸特写，右侧并列展示正面、90 度侧面、背面三张等高全身视图，
特写与全身视图都是同一角色，全身入镜，中性 A 字站姿，三张全身视图等高并排、头顶脚底对齐，
[年龄感 + 性别感 + 体态]，[五官特征]，[发型]，[服装 + 配饰]，
半身肖像与三个视图的脸、发型和服装完全一致，
纯白背景，柔和均匀的光线，动画电影质感，明显非真人照片，非写实肖像
```

## 描述顺序规则

把**最有辨识度的特征放在前面**，按此顺序落地 `appearance`（样貌）与 `styling`（妆造）的每个关键元素，不遗漏：

1. 身份锚点：年龄感（如"二十出头"）、性别感、体态（高矮胖瘦、姿态习惯）
2. 五官：脸型、眼睛、其他显著特征（疤、痣、眼镜等）——正脸特写尤其依赖这部分描写
3. 发型：颜色、长度、样式
4. 服装：款式、颜色、材质、状态（如"袖口有焊锡痕迹的皱褶工服"）
5. 配饰：只写有辨识度的，不堆砌

角色的性格特点要转化为外在气质与神态描写（如"憔悴" → "眼神疲惫、肩膀微垮"），不要直接出现性格词汇。

## 构图与一致性

- 左侧半身肖像：头部到胸口完整入镜，正面或轻微 3/4 角度，中性表情；面部占画面适中，不要超近距离大脸特写
- 右侧三张全身视图：同一角色的正面、90 度侧面、背面，**等高并排、间距均匀**，头顶与脚底在同一水平线上
- 半身肖像与三张全身视图必须是同一张脸、同一发型、同一服装——明确写出"半身肖像与三张全身视图的脸、发型和服装完全一致"
- 中性站姿、自然表情——方便作为参考图复用
- 柔和均匀的棚拍光，不要戏剧性光影（参考图要在各种场景下都能用）
- 必须强化 3D 动画角色设计感：略微简化的五官、干净的皮肤材质、柔和雕塑感面部、非真实人像质感
- 输出必须是纯中文，不要混入英文词汇

## 禁止事项

- 真人照片感、真实演员感、照片级皮肤毛孔、身份证照/证件照/棚拍写真
- 大幅正脸特写、脸部占据左半画面大多数区域
- 动态姿势、夸张表情、手持道具、与他人同框
- 裁切身体（全身视图必须 full body，头顶到脚底完整入镜；半身肖像必须头部到胸口完整入镜）
- 文字、标签、水印、签名
- 重阴影、彩色背景光、背景道具
